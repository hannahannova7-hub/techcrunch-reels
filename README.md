# techcrunch-reels

Личный инструмент автора блога про ИИ, IT, стартапы, финтех и венчур: свежая новость TechCrunch → готовый сценарий на русском для Reels и TikTok (60–90 секунд).

Это первая рабочая версия, проверенная на одном ручном прогоне. API, боты, Notion и расписание пока не подключены.

## Как это работает

1. **Сбор новостей — скрипт `fetch_news.py`.** Берёт RSS-ленту TechCrunch (`techcrunch.com/feed/`), оставляет материалы за последние 24 часа по темам блога (если пусто — за 72 часа), отбрасывает рекламу конференций и политику. Результат — файл `candidates.md` со ссылками, датами и рубриками.
2. **Выбор, проверка и сценарий — Claude Code.** По списку кандидатов Claude выбирает одну новость, проверяет её по первоисточнику и независимым изданиям (минимум три подтверждения) и пишет сценарий по правилам стиля автора. Готовый результат сохраняется в `result.md`.

## Скачать и запустить

1. Скачайте архив `techcrunch-reels-v0.1.0.zip` со страницы [Releases](https://github.com/hannahannova7-hub/techcrunch-reels/releases/latest) и распакуйте.
2. Установите [Python 3](https://www.python.org/downloads/), если его ещё нет (дополнительные пакеты не нужны).
3. На Windows дважды кликните `run.bat`. Рядом появится файл `candidates.md` со списком свежих новостей.

На Mac или Linux, а также из терминала:

```bash
python fetch_news.py
```

Можно указать период в часах, например `python fetch_news.py 72`.

## Телеграм-бот

Бот [@scenariostech_bot](https://t.me/scenariostech_bot) по команде `/news` присылает 5–7 свежих новостей TechCrunch по темам блога и помечает, какие из них уже присылал раньше. Команда `/history` показывает, что бот уже присылал.

Владельцу бота (`TELEGRAM_OWNER=ник` в `.env`) доступно ещё одно: любое сообщение без «/» становится задачей для Claude Code на компьютере. Бот отвечает «Принято», выполняет задачи по очереди и присылает результат. Задачи, пришедшие, пока бот был выключен, ждут подтверждения: `/tasks`, `/run`, `/skip`. Для этого Claude Code должен быть залогинен (`claude auth login`).

Присланные новости хранятся в базе SQLite, в файле `news.db` рядом с ботом. Поэтому история не пропадает, когда бот перезапускается. Файл создаётся сам при первом запуске и не публикуется.

Чтобы запустить своего бота:
1. Получите токен у [@BotFather](https://t.me/BotFather).
2. Создайте рядом со скриптом файл `.env` со строкой `TELEGRAM_BOT_TOKEN=ваш_токен`. Этот файл не публикуется.
3. Дважды кликните `run_bot.bat` (или `python bot.py`). Бот отвечает, пока окно открыто.

## Файлы

| Файл | Что внутри |
|---|---|
| `fetch_news.py` | Скрипт сбора свежих новостей TechCrunch |
| `run.bat` | Запуск скрипта двойным кликом на Windows |
| `bot.py`, `run_bot.bat` | Телеграм-бот с командами `/news` и `/history` |
| `storage.py` | Сохранение присланных новостей в базу SQLite (`news.db`) |
| `result.md` | Пример результата: сценарий про метки ИИ-музыки в YouTube Music и Deezer (14.10.2026), источники и ограничения проверки |
| `notes.md` | Заметки о ходе работы: шаги, ошибки, исправления — черновик для будущего гайда по вайбкодингу |
| `setup.md` | Система и версии инструментов, на которых всё запускалось |

## Правила сценария (кратко)

- Только русский язык, 60–90 секунд, длительность оцениваем по числу слов.
- Короткий хук, из которого сразу ясен предмет, затем контекст.
- Связная разговорная речь, термины объясняются при первом появлении, вопросы-переходы между частями.
- В конце вывод и один вопрос, понятный широкой аудитории.
- Без конструкции «не X, а Y», без аналогий и метафор, без политики, ничего не выдумываем.
- Надписи на экране и источники — отдельно от произносимого текста.
