# Скриншот для пруфа

Аня сама скриншоты снимает с трудом: делаем за неё.

1. Реши, что должно быть на кадре, и подготовь это:
   - **окно с выводом команды** — открой новое окно PowerShell (`Start-Process powershell -ArgumentList '-NoExit', ...`) с понятным заголовком и выводом; в начале команды `chcp 65001`, чтобы кириллица не ломалась;
   - **страница в Chrome Ани** — выведи Chrome на передний план (`WScript.Shell.AppActivate`); нужную страницу открой через `Start-Process chrome "<url>"`; нажимать в Chrome сам не можешь — попроси Аню;
   - **публичная страница GitHub** — встроенный браузер, `screenshot`, затем скопируй файл из tool-results.
2. Сними экран: `System.Drawing` → `CopyFromScreen` → сохрани в папку проекта как `proof-<что>.png`.
3. **Посмотри на снимок сам** (Read) до того, как отдавать: виден ли нужный текст, нет ли лишнего личного. Не то — переснять.
4. Добавь имя файла в `.git/info/exclude`, чтобы пруф не ушёл в публичный репозиторий.
5. Отправь файл Ане и выдели его в Проводнике. Напомни: перетащить в рамку «Скриншот» и **проверить, что картинка появилась**, до отправки.
6. Дай готовый текст для поля «Что сделал».
7. Новый приём — в «Уроки» ниже одной строкой с датой.
