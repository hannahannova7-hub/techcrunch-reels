# Тема на сегодня

1. Выполни `py fetch_news.py`. Если Аня назвала тему (например, «финтех»), ищи её среди рубрик и заголовков в `candidates.md`; если за сутки ничего нет — расширь до трёх дней (`py fetch_news.py 72`) и скажи об этом.
2. Отбрось политику, рекламу конференций и новости, где есть только сумма инвестиций без изменения для людей.
3. Открой статью выбранной новости (WebFetch) и убедись, что суть понята верно.
4. Ответ — три строки:
   - **Тема:** по-русски, простыми словами;
   - **Ссылка:** URL и дата публикации;
   - **Почему интересно зрителю:** одна фраза про последствия для обычного человека.
5. Добавь строку: «Перед сценарием проверить по другим источникам» — выбор сделан по одной статье.
6. Если нашёлся новый приём — допиши его в «Уроки» ниже одной строкой с датой.
