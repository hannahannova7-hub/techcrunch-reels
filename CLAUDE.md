# CLAUDE.md — techcrunch-reels

Личный инструмент Ани, блогера про ИИ, IT, стартапы, финтех и венчур: свежая новость TechCrunch → сценарий на русском для Reels/TikTok, 60–90 секунд. Аня не программист и терминал не открывает: все команды запускает агент, а ей отвечает по-русски, простыми словами. О себе Claude пишет в мужском роде («сделал», «нашёл»): женский род — это Аня.

## Запуск и проверка (Windows)
- Python вызывать через `py`, не `python`: в Git Bash `python` — заглушка Microsoft Store (exit 49). Перед запуском задать `PYTHONIOENCODING=utf-8`, иначе кириллица в выводе ломается.
- Сбор новостей: `py fetch_news.py` → строка «Найдено N кандидатов», файл `candidates.md`.
- Бот: `py bot.py` (в фоне). Запускать только один экземпляр: перед перезапуском убедиться, что старый процесс `bot.py` остановлен. Пара `py.exe` → `python.exe` с `bot.py` — это один бот, не два.
- Проверить базу без Telegram: подменить `storage.DB_PATH` на временный файл и дважды вызвать `bot.news_message()`. Ожидается: в первый раз все новости 🆕, во второй все ↩️.
- После правки `.bat` запустить его через `cmd /c`.

## Нельзя трогать
- `.env` (токен @scenariostech_bot) и `news.db` (история бота). Никогда не коммитить: **репозиторий публичный**. Перед каждым push проверять `git ls-files`.
- Правила стиля лежат вне репозитория: `C:\Users\Anita\Desktop\Claude перенос\Для ChatGPT\02 Виральный контент\Сценарии видео\` (`стиль сценариев видео.md`, `Правки Ани и мои повторяющиеся ошибки.md`, `все сценарии из Notion.md`). Читать перед каждым сценарием, но не копировать в репозиторий и не править.
- Платные сервисы, API для генерации, VPS и Railway не подключать без явного согласия Ани.

## Правила сценария, которые чаще всего нарушаются
- Длина считается по словам, примерно 150–220. Первый вариант вышел на 348 слов, и его пришлось резать.
- Под запретом: конструкция «не X, а Y», аналогии и метафоры, политика, выдуманные цифры и цитаты.
- Каждый факт подтверждать тремя независимыми источниками; перепечатки одного пресс-релиза считаются за один. Факт, найденный только в одном источнике, в сценарий не идёт.
- Дату события проверять отдельно от даты публикации.

## Грабли
- `.bat` с переносами LF ломает `cmd`. Нужен CRLF, это правило уже есть в `.gitattributes`, но новые `.bat` проверять всё равно.
- Веб-поиск отстаёт от новостей текущего дня. Список брать из RSS (`fetch_news.py`), подтверждения искать на сайтах первоисточников.
- musicbusinessworldwide.com возвращает 403 автоматическим запросам; источником такой сайт засчитывать нельзя.
- Задачи из бота выполняются через `claude -p` со списком `ALLOWED_TOOLS` в `bot.py`. На Windows команды идут через PowerShell, поэтому разрешение нужно в двух вариантах: `PowerShell(...)` и `Bash(...)`.
- Бот работает, только пока включён ноутбук. Это осознанное решение, сервер не нужен.
- Ход работы дописывать в `notes.md`: это черновик гайда Ани для новичков.

## Память и скиллы
Решения и договорённости из прошлых сессий: @memory.md. Повторяющиеся задачи описаны в `.claude/skills/` (`scenario`, `news-pick`, `proof-screenshot`). После удачного решения дописывай новый приём в раздел «Уроки» соответствующего скилла. Ночное задание по расписанию тоже пополняет память и «Уроки» через `extract_sessions.py`.
